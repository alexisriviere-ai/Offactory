# OF FACTORY — Klima Riv’Air

Application Windows pour la fabrication de plénums, la tôlerie, le dessin libre, le nesting et les étiquettes atelier.

## Installation

Les installateurs seront disponibles dans [Releases](https://github.com/alexisriviere-ai/Offactory/releases). Chaque ordinateur possède ses propres données locales.

Suivre la [procédure d’installation sur plusieurs PC](INSTALLATION.md), avec reprise de l’atelier existant avant la création du nouveau PIN.

Les futures mises à jour utilisent ce dépôt. Elles sont téléchargées en arrière-plan puis installées à la fermeture d’OF FACTORY ou depuis « Installer et redémarrer ». Les données de l’atelier sont conservées et sauvegardées avant l’installation.

Le dépôt contient uniquement les éléments de distribution du logiciel ; les chantiers, les noms de clients, les paniers et les documents des utilisateurs restent sur leurs ordinateurs.
